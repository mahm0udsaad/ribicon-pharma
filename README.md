# Ribicon Pharma Website

A responsive corporate website for Ribicon Pharma, built with Next.js, React, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production verification

```bash
npm run build
npm start
```

## Current routes

- `/` — Homepage
- `/about` — Company overview
- `/portfolio` — Therapeutic areas and approved product inventory draft
- `/services` — Commercial and partner capabilities
- `/contact` — Canadian office and inquiry routes
- `/privacy` — Staging privacy notice
- `/accessibility` — Accessibility commitment

## Content status

This is the first production-ready design milestone. Before public launch:

- verify the legal company name, Montréal address, contact routes, and affiliate footprint;
- complete regulatory/medical review of all product names and descriptions;
- confirm Canadian authorization, DIN/device licence, sponsor, strengths, and availability;
- replace the staging privacy notice with the approved policy and privacy-officer details;
- commission and review the complete French version;
- replace the supplied low-resolution PNG logo with the approved vector artwork.

Veterinary Diagnostics intentionally remains a non-promotional draft category until product details and approved claims are supplied.
